# **Customer Purchase Behaviour and Business Performance Analysis**

A complete end-to-end data analytics project exploring customer shopping trends and business performance using Python, SQL, and Power BI.

This repository contains an end-to-end retail data analytics project designed to analyze customer purchase behavior, sales trends, and overall business performance. The project demonstrates a complete analytics workflow—from raw data processing to insights, SQL analysis, and interactive dashboard creation.

## 📌 Project Overview

This project focuses on understanding how customers shop, what influences their purchasing decisions, and how different business factors such as shipping type, category, discounts, and age groups impact overall revenue.The goal is to showcase practical data analyst skills through data cleaning, transformation, exploratory analysis, SQL insights, and Power BI reporting.

## 📂 Project Components

### **1. Data Cleaning & Preparation (Python)**

* Handled missing values and transformed raw data into analysis-ready format.
* Standardized and cleaned column names.
* Created new features such as **age groups** and **purchase frequency (days)**.
* Evaluated discount and promo code consistency.

### **2. SQL-Based Business Insights**

Answered 10+ real business questions, including:

* Gender-wise revenue comparison
* Top-performing product categories
* Spending patterns of subscribed customers
* Discount usage analysis
* Customer segmentation (New, Returning, Loyal)
* Category-wise top purchased items
* Age-group revenue contribution

### **3. Power BI Dashboard**

A fully interactive dashboard showcasing:

* Total customers
* Average purchase amount
* Average review rating
* Sales by category
* Category performance
* Customer segmentation
* Revenue by age group
* Subscriber status insights

## 🛠 Tools Used

* **Python**: Pandas, NumPy, SQLAlchemy
* **SQL**: MySQL
* **Power BI**: Dashboard creation and storytelling

## 📈 Key Insights

* Clothing is the highest-performing category.
* Senior and Young Adults contribute significantly to revenue.
* Subscribers spend slightly more on average compared to non-subscribers.
* Discount usage varies across categories, with some categories having higher discounted purchases.
